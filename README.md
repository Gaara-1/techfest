# Techfest Mercury Landing Page

An original landing page concept for **Techfest, IIT Bombay** (30th edition, "An Aetherial Renaissance", 16 to 18 December 2026).

Theme: liquid mercury and chrome on a dark background, built with CSS only. No 3D assets, no Three.js, no WebGL.

## Run it

Open `index.html` in any modern browser. There is no build step, no npm and no other files.
The only external resource is Google Fonts (Unbounded and Manrope), which fall back to system fonts if offline.

## Deploy with GitHub Pages

1. Create a new public repository on GitHub.
2. Upload `index.html` (and this README) to the root of the repository.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then **Save**.
5. Wait one to two minutes. The site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Content sources

Text and figures come from the official Techfest channels: techfest.org (site metadata, competitions and workshops pages), and the official Techfest X, Facebook, LinkedIn and YouTube pages. Where something could not be verified, the copy stays generic. Reach figures (1,80,000+ footfall, 2,500+ Indian colleges, 500+ overseas colleges) are as published by Techfest for recent editions.
